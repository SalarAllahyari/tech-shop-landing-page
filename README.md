# TechShop Landing Page

A tech shop landing page built with HTML and CSS as a front-end practice project.

## Overview

TechShop is a landing page concept for an online electronics store, designed to showcase tech products in a clean and modern layout.

## Features

- Navigation bar with search bar and account/cart icons
- Hero section featuring a laptop product
- Featured products section with product cards
- Service highlights for shipping, warranty, and customer support
- Footer with navigation links, product categories, and contact information

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid

## What I Practiced

- Structuring a multi-section webpage with semantic HTML
- Styling layouts using Flexbox and CSS Grid
- Working with spacing, colors, borders, and typography
- Creating product cards and interactive hover states

## Project Status

This project was built for learning and practicing front-end development. Responsive design and further improvements may be added in future updates.
